How the implied value is built

Every row is scored by the same formula, from the snapshot's own figures only — no protocol name is ever special-cased:

implied = TVL × 0.30 × growth × maturity × breadth

  • Growth — the 7-day TVL change, clamped to −50%…+100%. Losses weigh more than gains (×0.9 below zero, ×0.6 above).
  • Maturity — 0.55 + up to 0.45 for up to 3 years tracked with no token. A protocol that ran for years without issuing a token has more to price in.
  • Breadth — +3% per extra chain, up to 4 chains. Multi-chain TVL is stickier.

“Records no token” means DefiLlama's record carries none — never that the protocol has none. Live-token protocols are shown separately, at the market's own value.
